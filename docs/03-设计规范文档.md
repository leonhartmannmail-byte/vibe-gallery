# 设计规范文档

## 整体风格
- 暗色主题（Dark Mode）
- 现代感、科技感
- 参考 reactbits.dev 的炫酷动效风格
- 简洁但不简单，动效丰富但不花哨

---

## 色彩方案

### 主色调
```
背景主色:    #0a0a0f (深蓝黑)
背景次色:    #12121a (卡片背景)
表面色:      #1a1a2e (悬浮卡片)
主强调色:    #6c5ce7 (紫色，主按钮/链接)
次强调色:    #00cec9 (青色，辅助高亮)
点赞色:      #ff6b6b (红色，点赞/喜欢)
文字主色:    #e8e8e8 (白色文字)
文字次色:    #8b8b9e (灰色次要文字)
边框色:      #2a2a3e (分割线/边框)
```

### 渐变
- 主渐变: `linear-gradient(135deg, #6c5ce7, #00cec9)` (紫→青)
- 卡片悬浮渐变光晕: 紫色/青色径向渐变背景

## 动效规范

### 页面过渡
- 淡入 + 轻微上滑 (y: 20px → 0, opacity: 0 → 1)
- 时长: 0.4s, 缓动: ease-out

### 卡片悬浮
- 轻微上移: y: -8px
- 阴影加深
- 封面图微缩放: scale(1.05)
- 时长: 0.3s

### 滚动入场（Stagger）
- 卡片依次淡入，每张间隔 0.1s
- 从下方 30px 滑入

### 点赞动效
- 按钮心跳放大: scale(1 → 1.3 → 1)
- 粒子飞溅效果
- 颜色从灰变红
- 时长: 0.4s

### 加载状态
- 骨架屏：灰色块呼吸灯效果
- 渐变闪烁: shimmer 动画

### 导航栏
- 滚动后背景模糊 (backdrop-filter: blur)
- 吸顶效果

## 组件视觉规范

### 作品卡片
- 封面图比例: 4:3 或 16:9
- 底部信息: 标题 + 作者头像 + 点赞数
- 悬浮时显示半透明遮罩 + 操作按钮

### 按钮
- 主按钮: 紫色背景 + 白色文字 + 圆角
- 次按钮: 透明背景 + 紫色边框 + 紫色文字
- 幽灵按钮: 透明背景 + 灰色文字

### 输入框
- 深色背景 (#1a1a2e)
- 聚焦时紫色边框高亮
- placeholder 灰色
