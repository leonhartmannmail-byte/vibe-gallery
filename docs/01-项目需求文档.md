# 项目需求文档

## 项目名称
Vibe Coding 作品展示网站

## 项目定位
一个类似 Dribbble 的 Vibe Coding 作品展示平台，让用户发布、浏览、点赞、评论 Vibe Coding 作品。

## 目标用户
- Vibe Coding 爱好者和创作者
- 想展示自己 AI 编程作品的用户
- 想浏览和学习他人作品的用户

---

## 核心功能

### 1. 用户系统
- 邮箱 + 密码注册/登录
- 用户个人资料（头像、昵称、简介）
- 个人主页展示自己发布的所有作品

### 2. 作品展示（首页）
- 瀑布流（Masonry）布局展示作品卡片
- 卡片内容：封面图 + 标题 + 作者 + 点赞数
- 排序方式：最新发布 / 最多点赞
- 滚动加载更多

### 3. 作品详情页
- 大图轮播展示多张截图
- 作品标题、详细介绍
- 外部链接（项目地址、Demo 链接等）
- 标签分类
- 点赞功能
- 评论区

### 4. 发布作品
- 填写标题、描述
- 上传封面图和多张截图
- 填写外部链接
- 选择/添加标签
- 提交发布

### 5. 互动功能
- 点赞（每人每作品一次，可取消）
- 评论（登录用户可发表评论）
- 标签筛选

### 6. 标签系统
- 预设常用标签（如 #React #动画 #游戏 #AI #全栈 等）
- 用户可自定义标签
- 按标签筛选作品

---

## 页面列表

| 路径 | 页面名称 | 说明 |
|------|----------|------|
| `/` | 首页 | 瀑布流展示所有作品，排序切换 |
| `/auth` | 登录注册 | 邮箱密码登录/注册 |
| `/publish` | 发布作品 | 作品提交表单 |
| `/work/:id` | 作品详情 | 大图展示 + 描述 + 评论 |
| `/profile/:id` | 个人主页 | 用户信息 + 其作品列表 |
| `/tag/:tag` | 标签页 | 按标签筛选展示 |

---

## 非功能需求
- 响应式设计（PC + 手机）
- 暗色主题为主
- 炫酷动效（参考 reactbits.dev）
- 图片需要压缩上传
- 加载状态需要骨架屏
