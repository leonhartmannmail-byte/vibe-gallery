# 开发执行步骤

## 总体原则
- 每次只做一个小功能，完成后验证通过再继续
- 每完成一步更新 dev-log 记录
- 遇到问题及时记录，不要硬撑
- 优先保证核心功能可用，动效后期再加

---

## 阶段一：项目初始化（预计 30 分钟）

### Step 1.1: 创建 Vite + React 项目
- 在项目目录下运行 Vite 初始化命令
- 安装所有依赖包
- 验证: `npm run dev` 能正常启动

### Step 1.2: 项目结构搭建
- 创建所有文件夹目录结构
- 创建基础文件（App.jsx, main.jsx 等）
- 验证: 目录结构正确

### Step 1.3: 全局样式初始化
- 创建 globals.css
- 设置 CSS 变量（颜色、字体、间距）
- 引入 Google Fonts
- 验证: 页面有基础样式

---

## 阶段二：Supabase 配置（预计 30 分钟）

### Step 2.1: 创建 Supabase 项目
- 注册 Supabase 账号
- 创建新项目
- 获取 URL 和 Anon Key

### Step 2.2: 数据库建表
- 在 SQL Editor 执行建表语句
- 创建 profiles, works, likes, comments 四张表
- 验证: 表结构正确

### Step 2.3: 配置 RLS 策略
- 为每张表设置 Row Level Security
- 设置读写权限策略
- 验证: 策略生效

### Step 2.4: 配置 Storage
- 创建 works 存储桶
- 设置访问策略
- 验证: 可以上传文件

### Step 2.5: 创建 Supabase 客户端
- 创建 src/lib/supabase.js
- 配置环境变量 .env
- 验证: 浏览器能连接 Supabase

---

## 阶段三：认证系统（预计 45 分钟）

### Step 3.1: useAuth Hook
- 创建 src/hooks/useAuth.js
- 实现：注册、登录、登出、获取当前用户
- 监听认证状态变化
- 验证: 能调用认证 API

### Step 3.2: Auth 页面
- 创建登录/注册表单 UI
- 表单验证（邮箱格式、密码长度）
- 对接 useAuth hook
- 验证: 能注册新用户并登录

### Step 3.3: Navbar 组件
- 显示网站 Logo
- 登录状态：显示用户头像 + 发布按钮
- 未登录：显示登录按钮
- 验证: 导航栏状态正确切换

---

## 阶段四：首页瀑布流（预计 1 小时）

### Step 4.1: useWorks Hook
- 获取作品列表（支持分页）
- 按时间/点赞数排序
- 按标签筛选
- 验证: 能获取数据

### Step 4.2: WorkCard 组件
- 封面图 + 标题 + 作者 + 点赞数
- 点击跳转详情页
- 验证: 卡片正确显示

### Step 4.3: MasonryGrid 组件
- 使用 react-masonry-css 实现瀑布流
- 响应式列数（1-4列）
- 验证: 瀑布流布局正确

### Step 4.4: Home 页面
- 排序切换 UI（最新/最热）
- 标签筛选栏
- 组合 MasonryGrid
- 验证: 首页完整可用

---

## 阶段五：发布作品（预计 1 小时）

### Step 5.1: ImageUploader 组件
- 支持选择多张图片
- 预览已选图片
- 上传到 Supabase Storage
- 验证: 图片能上传成功

### Step 5.2: Publish 页面
- 作品表单（标题、描述、链接、标签）
- 封面图上传
- 截图多图上传
- 提交到数据库
- 验证: 发布成功后跳转首页，能看到新作品

---

## 阶段六：作品详情 + 互动（预计 1 小时）

### Step 6.1: WorkDetail 页面
- 大图展示（图片轮播或画廊）
- 标题 + 描述 + 链接 + 标签
- 作者信息
- 验证: 详情页内容完整

### Step 6.2: LikeButton 组件
- 点赞/取消点赞
- 更新 likes 表和 likes_count
- 心跳动效
- 验证: 点赞功能正常

### Step 6.3: CommentSection 组件
- 评论列表展示
- 发表评论表单
- 验证: 能发表和查看评论

---

## 阶段七：个人主页 + 标签（预计 45 分钟）

### Step 7.1: Profile 页面
- 用户头像 + 昵称 + 简介
- 该用户的作品列表（瀑布流）
- 验证: 个人主页正确显示

### Step 7.2: TagPage 页面
- 按标签筛选作品
- 瀑布流展示
- 验证: 标签筛选功能正常

---

## 阶段八：动效润色（预计 1 小时）

### Step 8.1: 页面过渡动画
- 使用 Framer Motion AnimatePresence
- 淡入 + 上滑效果

### Step 8.2: 卡片交互动效
- 悬浮放大 + 阴影
- 滚动入场 stagger 效果

### Step 8.3: 点赞动效
- 心跳放大效果
- 粒子飞溅

### Step 8.4: 加载状态
- 骨架屏组件
- 加载中提示

### Step 8.5: 响应式适配
- 手机端布局测试
- 调整间距和字号

---

## 每日开发流程

1. 开始前：阅读 dev-log 最新记录，了解当前进度
2. 开发中：按步骤执行，每完成一个小步骤验证
3. 结束时：更新 dev-log，记录完成项和待办项
4. 遇到问题：记录到 dev-log，必要时调整计划
